# 账本事实与资金解释

## 目标

从当前 `planHash` 对应的正式计算结果取得证据，回答账本事实或解释资金变化。区分事实查询、现金流边界和投资建议：前两者可以完成，后者不在本 Skill 范围内。

## 输入

- 用户原问题及结构化感知结果；
- 当前计划摘要、关键收支、投资情景和可编辑对象；
- 当前 `planHash`；
- 已验证的工具 Observation。

金额以整数分表示，年份和月份保留明确单位。不能从模型语言补造缺失金额、时间或投资对象。

## 可用工具

- `read_overview`
- `get_annual_series`
- `inspect_year`
- `get_investment_capacity`

## 执行流程

1. 判断问题是概览、指定年份、原因解释还是投资现金流边界。
2. 核对时间、对象和单位；仅在它们影响下一步时追问一个最小问题。
3. 调用最小必要的只读工具，不重复读取相同计划版本和参数。
4. 核验 Observation 成功、计划版本一致、金额字段存在。
5. 回答用户问题，并标明事实来源、计算口径和不确定边界。

## 停止与异常

- 工具失败或结果不完整：停止引用金额，说明失败并建议重试。
- 年份超界或多个投资对象无法唯一定位：追问，不猜测。
- 用户要求具体投资产品或收益承诺：说明边界，可改为计算账本承受能力。
- 得到覆盖问题的有效 Observation 后停止，不为“更智能”继续调用工具。

## 验收

- 金额与正式计算结果一致；
- 回答直接覆盖问题，而不是重新询问已经存在的字段；
- “最多可投入”明确表述为现金流边界，不是推荐金额；
- 没有修改正式计划。
