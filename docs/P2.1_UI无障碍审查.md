## 发现与修复

1. **P1：手机首页链接没有可读名称**。`workspace/plan-workspace-client.tsx` 品牌文字在手机隐藏，只剩图标；读屏无法判断用途。补充品牌 aria-label、隐藏装饰图标并扩大点击区域。对应 WCAG 2.4.4 / 4.1.2。
2. **P1：浅色选中阶段对比度约 4.2:1**。`workspace/plan/plan-view.tsx` 绿色文字叠在浅绿色背景上未达到小字 4.5:1。保留选中背景，文字改用前景 token。对应 WCAG 1.4.3。
3. **P1：账本表头对比度约 4.47:1**。`workspace/ledger/ledger-view.tsx` 表头改用前景 token。对应 WCAG 1.4.3。
4. **P1：首页列表直接包含链接**。`themes/default/blocks/header.tsx` 为直接导航链接补充 `NavigationMenuItem`，恢复 ul/li 关系。对应 WCAG 1.3.1。
5. **P1：图标控件名称与交互缺失**。`shared/blocks/common/locale-selector.tsx` 语言按钮增加中英文可读名称；主题切换的 button 变体补名称与实际切换操作。对应 WCAG 4.1.2。
6. **P1：主题切换无减少动画及能力回退**。`shared/components/magicui/animated-theme-toggler.tsx` 在 reduce 或无 `startViewTransition` 时直接更新主题，保留状态变化；系统主题使用 resolvedTheme。对应运动偏好与浏览器兼容性，不误称所有动画必须禁用。
7. **P2：手机输入 14px**。工作台和 portal 抽屉使用独立 `data-life-ledger` 样式范围，手机输入至少 16px，减少输入时浏览器缩放风险，不改动脚手架其他表单。

共同模式：桌面隐藏文字后没有为图标保留名称；淡色背景复用正文色导致小字对比不足。修复应针对语义和计算样式，而不是额外堆叠解释文字。

## 未提交输入与历史导航补验

发现两个真实遗漏：点击年涨幅预设没有触发原 `onChangeCapture` 草稿标记；浏览器后退时 Next 路由先更新，取消虽然恢复 URL，但编辑器已卸载并丢掉草稿。

现已增加明确的预设草稿事件与带索引的工作台历史记录。工作台只按已确认的查询状态渲染，取消前进/后退通过回到原历史记录恢复地址，不新建重复条目，也不卸载原编辑区。确认离开则丢弃未提交值；已保存数据仍由正式计划提供。

`navigation.test.ts` 模拟多步后退、前进取消及确认，并检查历史长度不增长。真实浏览器验证涨薪预设→取消切换、取消后退保留 3%、取消前进保留 2%、确认前进及后退可继续操作。导航更新属于同文档行为；离开整个文档仍使用 beforeunload。

本轮单元测试 110 项、lint、TypeScript 检查通过。导航修复之后仍需最终生产回归，不沿用此前构建标识作为新代码的放行证据。
