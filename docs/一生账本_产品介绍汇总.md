# 「一生账本」产品介绍汇总

## 一句话介绍

**一生账本是一款面向中国个人与家庭的人生财务规划工具：用户把买房、结婚、育儿、换工作、换城市和退休等人生安排放到时间轴上，产品计算这些选择会如何影响未来几十年的现金流。**

它不是记录过去每一笔消费的记账软件，而是帮助用户回答：

> 按照我想过的人生，未来的钱够不够？什么时候压力最大？现在应该调整什么？

---

## 一、产品定位

### 产品是什么

一生账本把用户的：

- 当前资产
- 收入与日常支出
- 职业变化
- 家庭责任
- 购房与住房
- 投资安排
- 换城市生活
- 退休计划

统一转换成一份长期、按月计算的人生资金计划，并通过时间轴、资金曲线、收支图和关键结论展示结果。

### 产品不是什么

它不是：

- 逐笔消费记账工具
- 银行或证券账户聚合工具
- 投资荐股工具
- AI 自动生成财务数字的工具
- 对未来收入、房价或投资收益的保证

所有正式结果都来自可追溯的确定性计算模型，而不是由 AI 猜测。

---

## 二、目标用户

核心用户是中国城市中有一定收入、但面临多项长期选择的个人与家庭，例如：

- 计划买房、结婚或生育的人
- 在不同城市之间考虑生活成本和职业机会的人
- 希望提前退休或评估退休压力的人
- 收入尚可，但不知道长期资金是否足够的人
- 不愿连接银行账户，希望保护隐私的人
- 不懂复杂财务模型，但希望自己完成规划的人

早期最适合聚焦的用户，可以定义为：

> **25—45 岁，正在面对买房、换城市、家庭责任或职业变化的中国城市用户。**

---

## 三、核心用户价值

### 1. 把抽象的人生计划变成可计算结果

用户不再只是填写“收入”和“支出”，而是加入具体人生事件：

- 32 岁结婚
- 34 岁买房
- 35 岁生育
- 40 岁搬到杭州
- 45 岁暂停工作
- 60 岁退休

每项安排都会进入同一条人生时间轴和同一个现金流模型。

### 2. 提前看见未来压力

产品帮助用户发现：

- 第一次资金缺口什么时候出现
- 哪个年龄阶段压力最大
- 买房、育儿和退休是否发生叠加
- 退休时还有多少可用资金
- 是否存在“有房产但没有可用现金”的情况
- 调整金额或时间后结果会如何变化

### 3. 让用户边填写、边获得结果

产品不要求用户一次完成复杂问卷。

用户先填写最少的基线信息，就能立即得到初步结果；随后每加入一个人生安排，右侧报告和资金图都会更新，持续提供正反馈。

### 4. 保持计算透明、可解释

每个正式金额都能追溯到用户输入：

```text
人生安排
→ 标准化收入／支出／资产／负债
→ 月度计算
→ 年度汇总
→ 图表和结论
```

AI 将来只负责解释结果和帮助操作，不负责创造正式数字。

---

## 四、当前用户动线

```text
Landing 首页
  ↓
填写年龄、退休年龄、收入、支出和当前资产
  ↓
立即获得初步资金结论
  ↓
点击“加入人生大事”
  ↓
进入规划页面
  ↓
逐项加入职业、家庭、住房、投资、换城市和退休安排
  ↓
右侧报告即时更新
  ↓
进入分析页面
  ↓
查看完整图表、重点结论和未来的 Agent 解释
```

这一动线的重点是：

- 先给用户结果，再邀请补充信息。
- 每次只处理一类人生安排。
- 不让用户面对一张很长的财务问卷。
- 每次修改都能立即看到长期影响。

---

## 五、当前页面结构

### 1. Landing 首页

首页负责建立最小可计算基线。

用户只需填写：

- 当前年龄
- 退休年龄
- 计算终点年龄
- 当前可用资产
- 每月收入
- 当前每月支出
- 退休后每月自付支出

提交后立即展示：

- 当前规划是否可能出现缺口
- 首次缺口时间
- 计算终点可用资金
- 当前计算范围和口径

首页的主要行动按钮是“加入人生大事”，直接进入规划页面。

### 2. 规划页面

规划页采用左右双栏结构。

**左侧：规划人生安排**

用户选择并编辑：

- 现在
- 职业发展
- 家人
- 孩子
- 住房
- 父母
- 退休
- 投资
- 其他人生事件

**右侧：即时结果预览**

默认展示长期资金趋势，包括：

- 可用资金曲线
- 净资产对照
- 人生事件节点
- 退休时资金
- 计算终点资金
- 首次资金缺口

左侧负责“做选择”，右侧负责“看影响”。

### 3. 分析页面

分析页用于集中查看完整结果。

左侧报告包含：

- 长期可用资金和净资产
- 人生时间轴
- 投资收益与亏损区间
- 年度收入与支出
- 资金流向图
- 人生阶段支出
- 规则生成的关键重点

右侧为规划助手区域。目前保留产品界面和交互位置，正式 Agent 能力尚未接入。

独立“年度账本”页面已删除，但底层年度数据仍用于图表、快照、资金流和精确数据展开。

## 六、已经支持的规划能力

### 当前状态

- 当前现金、存款、房产和其他资产
- 当前收入
- 当前生活支出
- 当前年龄、退休年龄和规划终点

### 职业发展

- 每年涨薪
- 更换工作
- 副业收入
- 暂停工作
- 不同工作阶段的收入覆盖

### 家庭与人生事件

- 结婚和共同生活
- 家人支持
- 生育和育儿
- 教育支出
- 父母赡养与医疗
- 旅行、进修、购车
- 奖金、赠与和临时支出
- 自定义人生事件

### 住房

- 租房
- 收租
- 装修
- 全款购房
- 首付和贷款购房
- 等额本息月供
- 多套购房安排
- 房产、负债和可用资金分开计算

### 换城市生活

支持建立多个搬迁安排，包括：

- 当前城市
- 目标城市
- 搬迁月份
- 一次性搬迁费
- 搬迁后的住房支出变化
- 生活支出变化
- 收入变化

只填写城市名称不会改变资金结果。只有用户明确确认的金额才进入计算。

搬迁事件会显示在人生时间轴和长期趋势图中，点击后可以返回对应安排。

当前阶段不自动调用城市房价或生活成本 API。

### 投资安排

支持：

- 多个投资计划
- 投资本金
- 低波动、中波动、高波动和自定义
- 年化收益下限与上限
- 投资开始和结束时间
- 投资节点交互展示

正式财务结论永远按照本金计算。

投资收益或亏损只通过铺色区间展示，不进入：

- 首次资金缺口
- 最低可用资金
- 净资产结论
- 退休可持续性
- Agent 的正式结论

### 退休

支持：

- 退休时间
- 退休后每月生活支出
- 养老金和其他稳定收入
- 退休后长期资金变化

## 七、核心图表

当前产品通过以下图表解释用户计划：

### 长期资金趋势

展示：

- 可用资金
- 净资产
- 首次缺口
- 退休节点
- 人生大事节点
- 终点资金

人生事件会沿时间轴显示，用户可以通过节点返回对应规划。

### 年度快照

用户拖动年份后，只查看该年的：

- 收入
- 支出
- 年末可用资金
- 年末净资产
- 当年资金流向

避免一次展示几十年的复杂信息。

### 收入与支出

收入和支出使用同一金额刻度，保证图形高度能够直接比较。

### 资金流向

通过资金流图展示某一年：

```text
收入来源 → 当年可分配资金 → 生活、住房、退休、结余
```

### 投资波动区间

展示：

- 本金计划线
- 潜在收益区间
- 潜在亏损区间
- 每项投资的开始和停止时间

它只表达不确定性范围，不表示收益预测。

## 八、产品差异化价值

### 1. 从“记账”转向“人生选择”

多数记账产品解决的是：

> 我的钱花到哪里了？

一生账本解决的是：

> 我想这样生活，未来的钱够不够？

### 2. 以人生事件组织财务，而不是以金融账户组织

用户不需要先理解资产配置、现金流表或专业财务术语，只需要表达：

- 我什么时候买房
- 我是否想换城市
- 我准备什么时候生孩子
- 我想什么时候退休

产品负责把这些选择转换为财务影响。

### 3. 面向中国生活决策

产品使用人民币和中国用户熟悉的生活场景：

- 买房与首付
- 房贷
- 父母赡养
- 子女教育
- 换城市
- 养老金
- 家庭共同支出

未来可以继续接入城市房价、租金、生活成本和政策数据，但这些外部数据只作为候选值，必须由用户确认后才能进入正式计划。

### 4. 计算和 AI 分离

这是产品非常重要的可信度设计：

- 计算器负责正式结果。
- 规则系统负责发现重点。
- Agent 负责解释、追问和组织操作。
- 用户负责确认计划修改。

因此即使未来接入 AI，也不会出现 AI 随意修改数字或不同回答得出不同结论的问题。

### 5. 本地优先和隐私保护

当前计划默认保存在用户浏览器：

- 不要求连接银行账户
- 财务数据不进入 URL
- 正式计算不依赖服务器
- 支持 JSON 导出与恢复
- 准备完成后支持离线使用

这对于不愿上传家庭资产信息的用户具有明显价值。

## 九、当前技术与可信度

当前项目采用：

- Next.js、React、TypeScript
- Tailwind CSS
- Recharts
- IndexedDB
- Web Crypto
- Service Worker

核心计算按月运行，金额使用整数分，时间使用标准月份索引，避免长期浮点误差和日期歧义。

产品具备：

- 自动保存
- 历史快照
- JSON 导入与导出
- 数据完整性校验
- 多标签页修改冲突保护
- 中英文
- 深浅色主题
- 响应式布局
- 离线应用壳
- 自动化计算和界面测试

## 十、当前能力边界

目前尚未正式提供：

- Agent 在线问答
- 城市房价和生活成本 API
- 银行、支付宝、微信或证券账户同步
- 云端账号和多设备同步
- 税务精算
- 社保和养老金自动测算
- 保险规划
- 投资产品推荐
- 多人共同编辑
- 财务顾问服务

这些边界应当在对外介绍中明确，避免用户把情景规划误解为金融建议或未来预测。

## 十一、下一阶段规划

### 阶段四：Agent 解释

Agent 首期只完成三件事：

1. 解释当前结果。
2. 回答某项安排为什么产生影响。
3. 帮助用户定位需要修改的规划项。

例如：

- “为什么我在 52 岁开始出现资金压力？”
- “买房推迟三年会发生什么？”
- “我退休后的主要支出是什么？”
- “哪个阶段的支出最高？”

Agent 不直接修改正式计划；如果用户希望调整，Agent 生成待确认操作，由用户确认后执行。

### 阶段五：Agent 试算

在用户明确提出问题时生成临时方案，例如：

- 退休推迟两年
- 降低购房预算
- 调整搬迁时间
- 减少退休支出

先展示前后差异，用户确认后才写入正式计划。

### 阶段六：城市数据

城市 API 只用于提供候选数据：

- 参考房价
- 参考租金
- 生活成本
- 可能的收入区间
- 数据来源和更新时间

外部数据不会自动进入正式计划，必须经过用户确认。

## 十二、推荐对外介绍文案

### 短版

> 一生账本不是记录过去花了多少钱，而是计算未来想要的人生需要多少钱。把买房、育儿、换工作、换城市和退休放到同一条时间轴上，提前看见未来的资金变化。

### Landing 页面版本

> **把人生计划，算成一条看得懂的资金路线。**  
> 从今天到退休，把收入、住房、家庭、投资和人生大事放进同一份规划。先用几项数据获得结果，再一步一步完善，不需要连接银行账户。

### 产品差异化表达

> **不是替你预测未来，而是让你看清每一个选择的代价。**

### 当前最合适的产品价值主张

> **一生账本：以人生事件为核心、面向中国个人与家庭的长期现金流规划工具。**
