# Plan 页面交互设计

2026-10-14 更新，以本次用户确认的动线替代原长折叠表单。

## Direction contract

THESIS：人生阶段导航与单个编辑区。拒绝把通用记账表单和所有结果同时堆给用户。

OWN-WORLD：继承一生账本中性背景、绿色主操作、系统字体和 44px 控件；工作区不使用展示型装饰。

STORY：用户确认现在的基线，再选择与自己有关的人生事件；无需填完全部项目，随时查看概览。每次提交调用同一确定性计算器，不依赖 AI。

FIRST VIEWPORT：左侧 176px 阶段导航，右侧一个编辑面板。标题右侧“查看结果”；面板内一个主操作。手机用原生阶段选择器替代侧栏。修改影响只在实际修改过的编辑区显示，切换阶段不携带旧反馈。

FORM：用户明确选定「人生阶段导航 + 单个编辑区」，code-led；非随机视觉提案。主顺序：现在 → 职业发展 → 伴侣 → 孩子 → 住房 → 父母 → 退休。其他事件和高级假设为次级入口。

FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## 职业发展

- 每年涨薪：当前工资基线的年均实际涨幅，支持 0、正值、负值。现有月度复利计算保持不变；不是宣称每月调薪。
- 换工作：生效期间的新月薪，替换原个人工资；可单独设置新工作的年均实际涨幅。
- 副业：独立净收入，与工资相加，可延续至退休后。
- 暂停工作：所选月份工资为零，副业保留，结束后恢复原轨迹。
- 工资覆盖区间不允许相互重叠；错误不改写正式结果。
- 全部金额按今天购买力；实际涨幅不是名义涨薪，不再次叠加通胀。

## 状态与边界

保留 summary/detailed 双模式和原有计划数据。基础金额合法失焦后更新；新增事件点击“计入计划”后更新。未保存的事件切换阶段时提示。金额变动反馈不称“建议”，不把未经用户输入的未来当成事实。

房产现值不等于可用现金。现阶段住房事件表示现金开支，不自动生成房产、贷款或交易。

## 可用资金与净资产图表（2026-10-14）

本次为既有界面的局部呈现优化，沿用中性背景、克制的绿色与琥珀色。可用资金作为主面积图，零及以上用绿色、负值用琥珀色；横轴显示年龄并明确年末口径，提示框同时给出实际年份与年龄，纵轴以“万”为单位。保留零线、退休与首次缺口参考标记，帮助对应人生阶段和资金变化。

净资产作为可选虚线对照，与可用资金轨迹完全相同时自动合并展示，减少重复信息。保留图表的表格替代入口；可用资金与净资产口径仍然分开，确定性计算内核不变。相关实现位于 `src/features/life-ledger/workspace/overview/balance-chart.tsx`、`plan-charts.tsx`，坐标尺度位于 `src/features/life-ledger/analysis/balance-chart-scale.ts`。
