# 阶段 3–7 实施与验收记录

更新：2026-10-14。状态：核心能力已实现；以下证据不代表阶段 8 全部放行。产品最终顺序以用户后续确认为准，覆盖早期五节点及合并伴侣/孩子的草案。

## 阶段 3：规划与人生轨迹

- 实现七阶段：现在、职业发展、伴侣、孩子、住房、父母、退休。桌面阶段导航、移动选择器均使用单编辑区，允许随时查看结果。
- 职业区分实际年增长、换工作、额外副业和停工。换工作替换原工资；停工覆盖工资但保留独立副业。伴侣分担与额外支出可并存。
- `analysis/extract-life-trajectory.ts` 从正式计划提取状态和摘要；`workspace/plan/sections/` 保存独立编辑组件。
- 回归：`analysis/stage3.test.ts` 覆盖七阶段顺序、暂不考虑状态、事件起止、支出拆分守恒、退休修改和旧链接；`analysis/career.test.ts` 覆盖工资替换、增长和停工。
- 浏览器：六画像真实输入通过。职业截图 `evidence/stage3-career-desktop.png`；父母移动截图 `evidence/stage3-parents-mobile.png`。截图只证明对应时点和视图，不能替代当前全页视觉验收。

## 阶段 4：图表与年度账本

- 年度正式结果提供 `ageStart` / `ageEnd`。`analysis/chart-data.ts` 生成只读图表数据与关键年份。
- `workspace/overview/plan-charts.tsx` 展示年度支出堆叠图、表格替代和文本事实；`balance-chart.tsx` 以绿色/琥珀色面积区分正资金和缺口，可切换净资产虚线，完全相同则合并。
- 图表年度末值与月度最低值分别标明，避免错误地把月度极值画成年末值。账本提供关键/全部年份及月度详情。
- 回归：`chart-data.test.ts` 验证每分钱分类守恒；`balance-chart-scale.test.ts` 覆盖全正、全负、混合、零值与零点颜色分界。六画像浏览器比较图表终点与 P1 结果。
- 截图：`evidence/balance-positive-1440.png`、`balance-negative-375.png`、`balance-mixed-768.png`、`balance-compare-375.png`。

## 阶段 5：确定性分析

- `extract-facts.ts` 提取正式结果，`generate-insights.ts` 实现八条规则、排序、去重和最多三条展示；`generate-actions.ts` 提供最多三个试算入口。
- `simulate-action.ts` 的原因验证通过计划副本重算，不以金额最大直接断言原因。分析模块不调用 AI。
- 回归：`insights.test.ts` 每条规则包含命中、边界、不命中；另验证重复运行、数量上限和 trace 存在。`extract-facts.test.ts` 覆盖起始资金就是最低值的情况。
- 六画像浏览器覆盖分析与行动入口；房产贷款备份浏览器覆盖现金不足、净资产为正的说明。

## 阶段 6：试算与撤销

- 四类白名单补丁：移动收支时间、修改金额、退休时间、起始可用资金。候选校验后调用同一 P1 内核，抽屉显示差值、取舍和边界。
- 未确认不持久化，放弃不产生 revision；应用后可撤销一次。正式输入变化或外部标签页更新使旧试算不能应用。
- 回归：`analysis/simulation.test.ts` 覆盖四类补丁、非法值、不变性、原子应用、过期拒绝、撤销和原因验证；`workspace/workspace-reducer.test.ts` 覆盖冲突状态保留。
- 六画像浏览器逐一验证预览、放弃、应用、撤销及刷新恢复。`evidence/workspace-recovery.json` 覆盖双标签页试算过期和旧页不能覆盖新计划。

## 阶段 7：购买力、收益与依据

- 工作台统一当前购买力口径，职业增长与余额收益均为实际变化率；余额收益默认 0%，不额外重复叠加通胀。
- `workspace/components/evidence-drawer.tsx` 展示正式输入、来源、记录日期、模型/规则版本、月度 trace 和实际收益假设。
- 非流动资产计入净资产，不自动转为可花资金；正式 UI 无固定外币汇率日期或未完成的 Agent 入口。
- 回归位置：`calculation/`、`analysis/career.test.ts`、`analysis/personas.test.ts`；具体构建与全套测试结果汇总于阶段 8 记录。

## 合同与迁移

- 正式模型继续为 LifePlan 2.0.0。工资替换新增可选 `incomeTreatment: 'replace-salary'`，月度规则版本更新为 `monthly-cashflow-career-2026-10`；旧记录不要求包含该字段。
- 正式金额仍为整数分、时间为月索引、比例为基点。分析与图表只派生展示数据，不存第二份现金流结果。
- 既有房产和贷款备份经真实浏览器导入验证，损坏数据须明确恢复或导入，不静默替换。
