# 一生账本 P2.1 阶段 2 执行记录

> 阶段：工作台状态层与三视图骨架  
> 完成日期：2026-10-14  
> 状态：完成

## 1. 执行结果

计划工作台已从单组件内部状态重构为共享状态层，并形成三个独立视图：

```text
WorkspaceProvider（启动、计算、自动保存、冲突与备份）
  → 概览：结论、摘要、资金趋势与影响因素
  → 规划：正式输入与分类编辑
  → 年度账本：逐年核对与年度详情
```

三个视图共用同一份 `LifePlan` 和最后一次有效的 `MonthlyCalculationResult`。切换视图只更新 `tab` 查询参数，不重新挂载 Provider、不重新读取 IndexedDB，也不触发计划初始化。

## 2. 状态架构

- `workspace-provider.tsx` 负责 IndexedDB 启动、Landing handoff、确定性重算、自动保存、revision 冲突、导入、快照恢复和删除。
- `workspace-reducer.ts` 负责启动状态、计划、最后有效结果、计算状态、保存状态和错误状态。
- 计算失败时保留最后一次有效结果，不用部分结果覆盖界面。
- `plan-workspace-client.tsx` 只组合页面状态和视图，不再持有第二套存储控制器。

## 3. 三视图与导航

- 桌面使用带 `tablist` / `tab` / `tabpanel` 语义的顶部导航。
- 键盘支持左右方向键、Home 和 End，并使用 roving `tabIndex`。
- 移动端底部导航固定为三等分，并用 `aria-current` 标记当前视图。
- URL 使用 `?tab=overview|plan|ledger`，未知值回落到 `overview`。
- 标签切换使用 history push，浏览器前进/后退可以恢复上一个视图。
- 切换时保留 `section`、`year` 等安全的纯界面查询参数；金额与正式计划数据不进入 URL。

## 4. 年度账本迁移

- 从概览底部删除重复的折叠账本。
- 新增独立 `ledger/ledger-view.tsx`，复用同一份正式年度结果。
- 桌面表格只将年份做成明确的可操作控件，避免整行伪装按钮。
- 移动端保留按年列表；点击后打开年度详情抽屉。
- 抽屉支持遮罩关闭和 Escape 关闭，并为标题建立可访问关联。

阶段 4 会继续增加关键年份筛选、月度详情和更完整的追溯入口；本阶段不提前复制计算或扩展数据语义。

## 5. Landing 同步调整

阶段 2 收口时同步吸收了 Landing 的产品修订：

- 新增“起始可用资产（估算）”，以“万”为录入单位。
- 表单提交时显式换算为整数元，正式计划继续使用整数分。
- 结果区删除“最低可用资金”，保留“首次资金缺口”和“计算终点可用资金”。
- 该资产只表示可用于长期规划的存款和现金，不包含自住房等暂不变现资产。
